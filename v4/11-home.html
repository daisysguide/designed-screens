Two states · one canonical Home
Empty (zero-started)Triggered when the user has 0 topics started (no answers submitted yet). Greeting → onboarding nudge → Partner → Progress ("0 of 7 categories started") → bottom nav. No badge card. No Wry Observation card in this state. No separate "Nothing started yet" 📋 placeholder — the nudge owns the empty Up-next state, so a placeholder directly under "Pick your first topic." would be redundant.
PopulatedGreeting → Badge card (when earned) → Up-next topic card + tiered button (see Up Next — Topic Card) → Partner → Progress (category line) → Wry Observation (gated; see below) → bottom nav.
Folded inThis screen folds in what used to live on Screen 25 (Empty Home). 25 has been retired from the catalog.
Wry Observation card (gated easter egg) — FLAG FOR REVIEW
What it isA warm, specific observation drawn from the couple's data — e.g. "Fastest you've ever agreed: baby names. Slowest: the budget." Replaces the retired scored-divergence easter egg that was cut for pathologizing divergence. Never scores or ranks divergence. Never mentions being AI.
TreatmentDashed supplemental-card pattern (the system's "supplemental / authored content distinct from the main flow" convention — and correct for this card, which IS AI-synthesized content). No shadow. Faint rgba(95,69,242,0.03) tint fill inside the dashed border so the card has gentle presence rather than reading as a hollow outline. Soft italic framing line "A little thing we noticed" as the first element (12.5px, weight 500, sentence case, no tracking, muted) — a simplified daisy logomark is a future addition. Body: 13.5px regular (never italic — the observation must stay readable) at rgba(26,26,26,0.62). Reads as Daisy murmuring something she noticed — never a stat.
PlacementBottom of the content column, below the Progress category line and above the bottom nav. Subordinate to the Up-next card — it must never compete with Home's single next action.
GatingAppears only after a few reveals. Hidden in the empty / zero-started state. The exact reveal threshold is content/product to set.
SourceTemplated off real couple data (the doc page shows sample copy). The screen never fabricates an observation; if there's nothing specific to say, the card is hidden.
StatusFlagged for design review. This is the one net-new UI element in the v4 decisions pass. The placement, gating threshold, eyebrow label, and visual treatment are open — built to spec, not final.

Up-next selection — how the topic is chosen
RuleUp-next shows exactly one topic: the single highest-priority actionable topic for this user. Home owns one next move; it never lists a queue.
Priority ladderFirst match wins. 1 · Ready to reveal (both partners answered; this user can trigger the reveal) → 2 · Your turn (this user still needs to answer) → 3 · Available (not started, nothing pending; the next fresh topic to begin).
TiebreakerWithin a tier, most-recently-visited first (resume what you were in); then plan order for topics with no visit history.
ExcludedPartner's turn (nothing this user can act on — surfacing it would make Home a status board), Worth a conversation (post-reveal reflection; lives on Progress, and the Topics "Needs you" lens already excludes it), and settled / completed.
Trio boundaryHome = the one next move · Topics "Needs you" lens = the full Your-turn + Ready-to-reveal queue · Progress = Worth-a-conversation reflection. Non-overlapping by design.

Behavior notes
Greeting updates by time of day: "Good morning" / "Good afternoon" / "Good evening".
Top-right avatar is gone in both states. Settings is reached via the bottom-nav Settings tab.
Empty state shows the onboarding nudge in the Up-next slot. A separate "Nothing started yet" 📋 block is not rendered — the nudge owns the empty Up-next state.
If the user has no partner linked and no topics started, the partner "Invite your partner" nudge appears below the onboarding nudge as the secondary ask. Two nudges is acceptable; the hierarchy must read onboarding-first.
Up next (populated) shows the single highest-priority actionable topic — Ready to reveal → Your turn → Available — with most-recently-visited as the in-tier tiebreaker. Partner's turn, Worth a conversation, and completed topics are excluded. The three populated variants vary only in pill + button label + route (Ready to reveal: charged cyan pill / "See where you landed →" → 19 · Your turn: cyan pill / "Answer now →" → 16 · Available: no pill / "Start this topic →" → 16). See the Up-next selection spec card.
Partner section is avatar-less on Home in every state. Other screens still use avatar-md; the Home variant is the exception (see design system, Partner Status Block).
Progress is a single category line. No tiles, no alignment score — alignment is a distribution on Progress (12), not a number on Home.
Wry Observation (gated easter egg) sits at the bottom of the content column, below Progress and above the bottom nav. Populated states only; hidden in the empty / zero-started state. Subordinate to the Up-next card — never competes with the single next action. Never scores or ranks divergence; never mentions being AI. Replaces the retired scored-divergence easter egg. Flagged for design review.
Three transition triggers stay distinct: nudge dismiss + Up-next populate fire on first topic intro view (16); Progress increments fire on first answer submitted.
Tapping the active Home tab scrolls back to top.
No em dashes in any on-screen copy.
Demo state switcher (doc page only)

The row of pills above the phone is a doc-only affordance, modeled on Screen 12's state switcher. Two axes: layout (Empty / Populated) × partner sub-state (Linked / Pending / No partner). The Empty + No partner combo shows the two-nudge hierarchy (onboarding primary, partner secondary).

A second Up-next tier row previews the three populated variants the selection rule can resolve to: Ready to reveal · Your turn · Available. Tier preview is meaningful only in the populated layout — the row hides in the empty layout, and tapping a tier while on an empty tab jumps to the matching Populated · {partner} state.
