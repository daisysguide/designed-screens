Topic state model

A topic has two phases. The row shows whichever phase is live — never both. Action phase is per-user (opposite for each partner) and appears as a right-aligned pill before the reveal. Alignment phase is shared (one value per couple) and appears as a colored sub-divider band inside the Revealed card after the reveal.

Action phase · per user
Not started
No pill · clean row · neither partner has answered.
Your turn
Cyan pill · fill #9decfa · border #7fe3f7 · text #0b5263 · partner answered, user hasn't.
Ready to reveal
Cyan pill on an animated multi-hue gradient row (cyan → lilac → pink) · highest-energy state · both answered, user hasn't opened reveal yet · reduced-motion safe.
Partner's turn
Quiet gray pill · no border · text rgba(26,26,26,0.6) · user answered, waiting on partner. Label uses partner's first name ("Sam's turn"); falls back to "Partner's turn" if unlinked or the name is too long. Never truncate a name.
Alignment phase · shared
Fully aligned
Brand-green band · bg rgba(119,234,175,0.30) · text #157a46 · couple answered the same.
Mostly aligned
Lighter brand-green band · bg rgba(150,241,198,0.42) · text #2e7d52 · close, with minor gaps.
Worth a conversation
Orange band · bg rgba(255,173,108,0.34) · text #995611 · sentence case. Deliberately off the green→red axis — this is an invitation, not a warning.

The descriptions above are summaries. How a topic actually lands in one of these three states — per-question 0–1 scoring, the spine weighted heaviest, the weakest-link override, the deferral rule — lives in v4/alignment-logic.md. The row reads from the same computed result the Alignment Reveal does; it never recomputes.

"Needs you" lens

A one-tap filter that flattens the list to just the pre-reveal "your move" topics, in priority order. Third distinct job in the trio — Home = the single next action, Progress = worth-a-conversation reflection, Topics "Needs you" = the full pre-reveal queue when you want to do more than one thing. Must NOT surface Worth a conversation (that stays on Progress) and must not become a second Home.

Chip label"Needs you" — label only · no icon (a sparkle reads as another product's AI mark, and it collides with the app's own ✨, which is the "for you two / personalized synthesis" mark) · no count (presence already says "there's something"; numbers turn calm into a backlog at scale, and the breakdown lives inside the lens)
Chip colorThe "your move" cyan — soft-cyan fill (--cyan-soft), --cyan-strong border, --cyan-text text. Active state fills --cyan-strong and appends ✕
PositionIn the floating dock above the bottom nav, beside the grouping toggle
Default layoutInline — one row: [ Category | Stage ]  [ Needs you ]
Fallback layoutStacked — reflows to two lines (Needs you on its own line, toggle on the other) when the inline row can't fit: small viewports, large Dynamic Type / accessibility text, or longer localized labels. Triggered on actual overflow (container query + flex-wrap safety net), not a fixed width breakpoint
VisibilityOnly rendered when actionable N ≥ 1. At N = 0 the dock shows just the grouping toggle
"Actionable" =Your turn + Ready to reveal only (per-user, pre-reveal). Excludes Worth a conversation, Partner's turn, Not started, and any settled/aligned state
Order in lens"Ready to reveal · N" first (magic-row treatment + charge pill — most time-sensitive, both partners have answered), then "Your turn · N" (cyan pill)
EnterTap chip → list flattens to the prioritized queue · grouping toggle hides · chip fills cyan and appends ✕
ExitTap the active chip → restores the full list in whatever grouping was active before. The floating chip stays reachable no matter how far you've scrolled

"All clear" state

When nothing pre-reveal is actionable for the user, the list goes quiet. Every "your move" affordance drops away so the screen stops shouting when there's nothing to shout about. Revealed/alignment content is unchanged — settled outcomes aren't pending actions.

TriggersActionable count = 0 (Your turn + Ready to reveal). All pre-reveal topics are either Not started or Partner's turn.
What dropsReady-to-reveal gradient row + charge pill · Your-turn pills · "Needs you" chip · the dock divider · category-header dots that flag actionable groups · the "Not revealed yet · N" eyebrow above the peek list
What staysFull topic list with all groups · Category / Stage toggle in the dock · revealed cards with alignment bands · "Manage topics" link · screen header / subtitle
Dock contentsJust the grouping toggle, no chip and no divider. The pill is the same white frosted-glass shape; it just contains less.
Peek behaviorMixed-phase groups still peek (left page: unanswered, right page: revealed) — but the left eyebrow is gone and rows are plain. The peek now reads as "what's left to do" without urgency markers.
Partner's-turn pillStays visible — it's information, not a call to action. The user isn't blocked on themselves.

Behavior notes
All 7 categories present in By-category view; 4 stages in By-stage view. Default: first actionable group expanded, rest collapsed.
Action-phase states are per-user and change the pill in place — rows don't relocate as each side answers.
Alignment is shared and seeded at reveal time. Both partners see the same band for a given revealed topic.
"Anyone can open a loop, closing takes both" — moving a settled topic to Worth a conversation is unilateral and instant; moving back to settled (Fully / Mostly aligned) is propose-and-confirm.
No Locked state for now — the prediction-card lock-out is dropped from this screen.
Partner's-turn pill label uses the partner's first name (e.g., "Sam's turn"). Falls back to "Partner's turn" if unlinked or the name is too long — never truncate a name.
"Manage topics" link always visible top right — never scrolls away.
Subtitle count updates live ({plan} · {revealed}) as topics move through reveal. Templated off the data layer — same plan source as Progress (45 in this example, not the full library of 51).
Category and stage names in Title Case verbatim — same as throughout the app.
"Needs you" lens flattens the list to actionable topics only (Ready to reveal → Your turn). Chip is absent when there's nothing to act on; while on, the grouping toggle hides and the chip shows ✕ to exit. Worth a conversation deliberately stays out of this lens — that belongs on Progress.
