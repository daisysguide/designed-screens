Topics tab is active. Tapping any topic row → Screen 16 Topic Intro. "Manage topics" top right → Screen 15 Manage Topics.
Topic state model

A topic has two phases. The row shows whichever phase is live — never both. Action phase is per-user (opposite for each partner) and appears as a right-aligned pill before the reveal. Alignment phase is shared (one value per couple) and appears as a colored sub-divider band inside the Revealed card after the reveal.

Action phase · per user
Not started
No pill · clean row · neither partner has answered.
Your turn
Cyan pill · fill #9decfa · border #7fe3f7 · text #0b5263 · partner answered, user hasn't.
Ready to reveal
Cyan pill on an animated multi-hue gradient row (cyan → lilac → pink) · highest-energy state · both answered, user hasn't opened reveal yet · reduced-motion safe.
Partner's turn
Quiet gray pill · no border · text rgba(26,26,26,0.6) · user answered, waiting on partner. Label uses partner's first name ("Sam's turn"); falls back to "Partner's turn" if unlinked or the name is too long. Never truncate a name.
Alignment phase · shared
Fully aligned
Brand-green band · bg rgba(119,234,175,0.30) · text #157a46 · couple answered the same.
Mostly aligned
Lighter brand-green band · bg rgba(150,241,198,0.42) · text #2e7d52 · close, with minor gaps.
Worth a conversation
Orange band · bg rgba(255,173,108,0.34) · text #995611 · sentence case. Deliberately off the green→red axis — this is an invitation, not a warning.

Behavior notes
All 7 categories present in By-category view; 4 stages in By-stage view. Default: first actionable group expanded, rest collapsed.
Action-phase states are per-user and change the pill in place — rows don't relocate as each side answers.
Alignment is shared and seeded at reveal time. Both partners see the same band for a given revealed topic.
"Anyone can open a loop, closing takes both" — moving a settled topic to Worth a conversation is unilateral and instant; moving back to settled (Fully / Mostly aligned) is propose-and-confirm.
No Locked state for now — the prediction-card lock-out is dropped from this screen.
Partner's-turn pill label uses the partner's first name (e.g., "Sam's turn"). Falls back to "Partner's turn" if unlinked or the name is too long — never truncate a name.
"Manage topics" link always visible top right — never scrolls away.
Subtitle count updates live ({plan} · {revealed}) as topics move through reveal. Templated off the data layer — same plan source as Progress (45 in this example, not the full library of 51).
Category and stage names in Title Case verbatim — same as throughout the app.
