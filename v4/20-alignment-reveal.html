Four answer types
TypeRender
Question headingDark, left-aligned, ~14px / 600. Same for every type.
Single-selectTwo chat bubbles. Jordan = white, left, tail bottom-left. You = cyan (rgba(127,227,247,.22) / border .55), right, tail bottom-right. Name labels above each bubble.
Multi-selectSame chat bubbles; bubble body holds option pills. .ms-pill-shared (green) for shared picks, .ms-pill-unique (gray) otherwise. N in common centered below.
SliderKeeps its visual track (not a bubble). Value-mapped markers (left = low end). You marker cyan-filled, dark-cyan You number (#0f7e99). Corner-number order follows value; You wins the right corner on ties. Exact tie merges to one marker + "Same answer" in green.
RankingPer-item card. Each row: option name + You chip (cyan) + Jordan chip (neutral) showing rank numbers. Default order = your ranking. Tap the card to re-sort by Jordan (FLIP reflow, 0.42s); tap again returns. Inactive-sort chips dim to 0.5. Cue line below + a note line ("Same call on X · biggest split on Y").
Three alignment states
🎉 Fully aligned
Strong agreement across the board. Pill green.
😌 Mostly aligned
Shared foundation with one or two real gaps. Pill is the lighter green, not yellow.
🤔 Worth a conversation
Answers diverge meaningfully on one or more questions. Pill warm-orange.
Alignment is computed across all questions, not per question. One pill summarizes the whole topic; the canonical mapping lives in v4/alignment-logic.md. The pill's tint here mirrors that result; the For You Two card tints to the computed state even after the user overrides status.
For You Two — state-tinted
TreatmentNo dashed border. Faint state-tinted background + soft state-colored border. The card is the payoff, not an aside.
Tint sourceThe computed state (does not change when the user overrides status).
MarkInline Venn SVG (two overlapping rings) in label-ink — legibility never depends on the tint. Replaces the ✨.
BodyWarm synthesis. Never mentions AI. Sentence case. No em dashes.
Model boundaryCode computes the alignment per v4/alignment-logic.md; the model only writes the words, so pill and copy can never disagree.
Slider — value-mapped + tie rule
Marker position(value − min) / (max − min) × 100%. Low end left, high end right.
You markerCyan fill #7fe3f7, 2px solid #3bb4d4.
Jordan markerWhite fill, dark border.
Range fillFaint cyan rgba(127,227,247,.3) between the two markers.
Corner numbersLower value → left corner, higher → right. You wins right corner on ties (You ≥ Jordan).
You number colorCyan-dark #0f7e99 (Jordan stays ink). New cyan-text token; will be promoted in the design-system pass.
Exact tieMarkers merge to one ~18px marker (cyan fill + 2.5px solid #1a1a1a ring). Delta reads "Same answer" in green. Both corner numbers still show.
Edge clampMarkers/numbers at min or max nudge inward a few px to avoid clipping.
Ranking — tap to reorder
Default sortYour ranking, low → high.
Tap cardRe-sort by Jordan. Tap again returns to yours.
ReflowFLIP: capture row tops, reorder, invert with translateY, transition transform 0.42s cubic-bezier(.4,0,.2,1) to 0.
DimmingChips for the partner you're not sorting by drop to ~0.5 opacity, so it's clear whose order you're reading.
HighlightsRows with gap 0 → faint green tint. Biggest-gap row → faint orange tint.
Cue"⇄ Ordered by your ranking · tap for Jordan's" and reverse.
Note"Same call on {option} · biggest split on {option}."
Reduced motionReorder is instant.
Single editable status + provenance
DefaultThe computed alignment.
Worth → settleLands at Mostly aligned (cannot jump straight to Fully).
Anything → reopenLands at Worth a conversation. One-tap consent valve.
Who can actEither partner, unilaterally, anytime. Instant.
Top pillThe current state, label only.
Bottom blockCentered prompt + echoed pill + provenance + action link. Returning to the computed value clears provenance.
Provenance string"Computed: {original}. You {settled\|reopened} this on {date}."
Daisy crown + petal burst
Daisy../images/daisy.svg, ~64px, centered. Blooms on entrance (scale 1 → 1.16 → 1 + slight rotate, ~0.85s, spring easing).
Petal burst~14 petals scatter radially from the daisy and fade (~0.9s). Tinted to the state (Fully #77eaaf / Mostly #96f1c6 / Worth #ffad6c), with ~1 in 5 gold #ffd755.
AlwaysBurst fires for every state on entrance — agreement is not framed as the only "win."
Reduced motionDaisy static, no bloom, no burst.
Revisit modeStatic daisy, no burst.
