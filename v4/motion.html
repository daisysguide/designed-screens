Motion

A small set of named durations and one standard easing — the same two-layer discipline as the other foundations. Most motion is short and functional; the expressive one-offs are documented per-component choreography, not tokens.

Reduce motion is on. Decorative and looping animation is suspended and one-shots resolve to their final, static state — the same behavior prefers-reduced-motion: reduce produces app-wide.

Easing

One standard curve for functional transitions.
ease-standard
cubic-bezier(.4, 0, .2, 1)
The CSS ease keyword currently stands in as a near-equivalent shorthand across several component cards (switch, slider, state change). Treat it as the same intent and standardize new work on ease-standard; the ranking FLIP reflow already uses this curve explicitly.
